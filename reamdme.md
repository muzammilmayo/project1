# Employee Management Dashboard
## Project Description
- This project is an Employee Management Dashboard.
- It is built using HTML, CSS, and JavaScript.
- It allows users to manage employee records without using a backend.
- All employee data is saved in browser Local Storage.

## How It Works

- User enters employee details in the form.
- JavaScript checks and validates the entered data.
- Employee data is stored in Local Storage.
- Saved data is displayed on the dashboard.
- Data remains available even after refreshing the page.

## Features

- Add new employees
- View employee records
- Edit employee information
- Delete employee records
- Save data using Local Storage
- Load existing data automatically
- Responsive user interface
